COMMAND TO REMEMBER ALL TIME

1. uname = check OS
2. pwd	==	where am I
3. cd	==	change directory
4. ls	==	list content of directory
5. ls -l ==	show details like, permission, owner, size and modification date
6. cat	==	print content of file

7. | = Pipe ==	used to filter, it is used to pass the output of one command as input to another, it also allows you to chain multiple commands together

8. grep is to filter a word or "phrase" while using | (pipe)
Example: cat error.log | grep database.	this ONLY show lines that has database

9. >= Redirection, Redirect the output of a command to a (NEW)file.
Example: cat error.log | grep database > NEW-FILE

10. cp	==	copy a file to thesame or a diff location
Example: $ cp error.log /root/error.log.backup

11. wc	==	word count 
		-l count lines
		-w count words
		-c count bytes
		-m count character (useful for UTF-8)
		-L find the longest line length
Example cat error.log | grep database | grep "a phrase" | grep wc -l

12. find ==	this is used to find a file. either full name or half/part name. Example $ find location -name "*.conf"
	      $  $ find location -name "*.conf*"

13. diff ==	its used to find the difference in the content of two files
Example: $ find file-1 file-2

14. curl ==	Client URL, Used to transfer data from OR to a server using various protocols like HTTP, FTP etc. It is commonly used for interaction with APIs and debugging NETWORK requests.
Example: $ curl -I http://localhost:port-number
