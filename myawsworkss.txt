To install the AWS CLI on CentOS 10, (ask Google) follow these steps:

•	Update the System
Ensure your system is up to date:
sudo dnf update
 
•	Install Required Packages
Install the necessary packages:
		sudo dnf install unzip curl
 
•	Download the AWS CLI
Use the following command to download the AWS CLI installation script:
$ curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"

•	Unzip the Installer
Unzip the downloaded file:
	$ unzip awscliv2.zip
 
•	Run the Installer
Execute the installation script:
	$ sudo ./aws/install

##You need a key pair to be able to SSH into EC2 instance, do it when creating instance

You must have a SUBNET in VPC, so create both public and private subnet always together.

Subnet IP address must always be within the VPC IP range

Gateway connect your VPC to outside/another network

Every VPC have a default Route Table which makes instances in the same VPC to communicate.

Create diff Route Table for both public and private subnet

Associate Subnet to Route Table.  ----  Go to RouteTable to do it

NAT Gateway
Nat Gateway – Create Gateway connect to public subnet, select Elastic IP.

Network Access Control list, it is stateless, it DOES NOT REMEMBER what goes in or out of instance,
so you must set the rule for what goes in and rules for what comes out.
--- it’s like a firewall to protect the subnet

Security group is STATEFULL, it remembers what goes in and what comes out of instance,
it only require one way rule set.
